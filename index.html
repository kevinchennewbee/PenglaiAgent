为什么叫蓬莱？蓬莱是中国古代神话中的海上仙山，可望而不可即。但这个项目想说的是：那些看似遥远的 AI 能力，其实可以触手可及——装在你自己的机器上，用你熟悉的工具去驱动。

这是一个"可望可即"的蓬莱。

快速开始

开始安装

三种方式，选你顺手的

1

下载 0.3.6 安装包（macOS Apple Silicon / macOS Intel x64 / Windows x64）。桌面包已内置 Penglai runtime、standalone Python 和核心依赖。

https://github.com/kevinchennewbee/PenglaiAgent/releases/latest
2

打开安装包，拖动到 Applications（Mac）或按提示安装（Windows）。首次启动不需要手动安装 Python、clone 源码或现场 pip。

3

启动蓬莱桌面客户端，跟随向导配置你的第一个 Agent。应用内升级清单默认使用国内友好的 gh-proxy 镜像 URL。

打开「蓬莱」应用 → 点击「开始配置」
1

一行命令安装蓬莱 CLI（自动备好 Python 与依赖）

curl -fsSL https://raw.githubusercontent.com/kevinchennewbee/PenglaiAgent/main/install.sh | sh
2

启动 Runtime Hub 服务（飞书 + 微信 + 调度器）

penglai start
3

开始对话（直接进入 TUI，等价上游 GA tuiapp_v2）

penglai
1

通过 pip 安装蓬莱核心（PyPI 包名 penglai）

pip install penglai
2

运行安装向导（自动配置 LLM、身份、渠道、能力）

penglai setup
3

按需局部补配（如只补飞书）

penglai setup --only feishu

近期 0.3.x 工作留痕

官网保留最近 0.3.x 系列的关键发布记录，便于快速理解蓬莱从 Runtime Hub 到桌面发行的连续演进。

🌌

v0.3.6 · 2026-07-12

Worldline 可验证发布：将对话回溯从临时界面补全为可持久恢复的分支时间线，续接会话时恢复工作记忆并校验原生日志；同时修复长提示词临时文件竞态、浏览器管道中断、Claude 拒绝响应收口和 Companion 失败结果记录。三平台发行门禁、版本一致性与 Rust 下载回退同步加固。

🔏

v0.3.5 · 2026-07-03

可信发布门禁与主动陪伴 Loop 基座：三平台桌面发布继续保留真实安装包验证，新增 release tag 签名校验门禁、GitHub Release 产物聚合、latest.json 更新路径，以及 Companion Loop 的策略 / 事件 / 记忆接口骨架。主动陪伴仍是可验证基座，不宣称已经完成生产自适应闭环。

🛡️

v0.3.4 · 2026-06-30

可信化维护发布：保留 0.3.3 的三平台桌面分发，重点修复桌面一键升级执行链路、Runtime Hub 取消、Conductor 认证、inline eval 暴露、长期记忆读时扫描、外部工具结果不可信标记、微信/企微媒体路径清洗、LLM failover 分类，以及 updater 元数据缺包/缺签名时 fail-closed。

🏁

v0.3.3 · 2026-06-29

Intel Mac 桌面支持发布：新增独立 macOS Intel x64 DMG 与 darwin-x86_64 updater 元数据，保留 0.3.2 内置运行时策略；首次设置接入 Hermes / OpenClaw 迁移预览，默认不暴露明文 secret；状态变更操作加入二次确认。

📦

桌面本地运行环境发布：macOS Apple Silicon DMG 与 Windows x64 安装器内置 Penglai runtime、standalone Python 和核心依赖；首次启动不再要求用户安装 Python、clone 源码或现场下载 Python 包；latest.json 默认指向 gh-proxy.com 资产地址。
