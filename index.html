缘起

一个不会写代码的人，和他的 AI 管家

我做了十年网络工程、安全和运维，但不会写代码——一行都不会。这个仓库里的每一行，都是用 AI 编程工具一句话一句话「说」出来的。蓬莱本身就是它想证明的东西：AI 时代，普通人也能为自己造工具。

0.3 验证了那条叙事：把 Agent 搬进你已经在用的聊天工具，数据全部留在自己的机器上。但 Python 时代的它，审批留痕还停在「方向对、实现半成」。0.4 是一次认真的重写——TypeScript、强类型协议、Pi 开源内核，把聊出来的想法做成内核级能力。

蓬莱是《史记》里的海上仙山，人人听说、少有人到。今天的 AI 之于普通人，就像当年的蓬莱——API、终端、配置文件是海上的雾。我们想做的，是把仙山搬进你的聊天窗：不用学航海，会发消息，就能到。所谓「八仙过海，各显神通」——多模型、多渠道，各展所长，服务同一个你。

—— 蓬莱作者，写于 0.4 重写之后
一个对话面

同一个它，项目只改变边界

没有"精简模式"。你在终端里聊天的那个它，和它在受信项目里写文件的那个它，是同一个——工具、预算、审批不因标签而变，变的只是边界。

浮动FLOATING

锚定在它自己的地盘（记忆与草稿）：提问、起草、把想法说出口。

  • 陪你聊、答问题、读文件，流式回合即问即答
  • 聊到要动项目文件的活儿，它会提议锚定——而不是擅自开工
  • 全工具集始终在它手里；真正拦住它的是审批与 jail，不是"模式"
项目锚定ANCHORED

锚定到你显式信任的项目目录：长循环自主干活，全程在项目 jail 内。

  • 写代码、跑命令、改文件，全程在 realpath 校验的 jail 内
  • 锚定 ≠ 信任：开工前要你点头，关键操作可审批、可回退
  • 完工自动复盘，证据与成本落账，回到对话还能引用产物

一个权限旋钮（plan → confirm → auto-edit → full）调节问你多频繁；四级审批是同一副骨架

差异化

三件事，别人给不了

其一

入口

住在 IM 里的随身在场

不用新装 App，不用守着终端。它住在你的飞书里——通勤路上、午休间隙，一条消息就到。Agent 的下一站不在 IDE 里，在你每天打开的那个聊天窗。

其二

主权

持久数据自托管在你机器上

聊天、记忆、能力与凭据都由你的机器持久保存，日志先脱敏再落盘，也不进入分发包。调用你选择的 BYOK 模型时，完成当前任务所需的提示与上下文会发送到该模型端点。

其三

进化

技能树长在本地

每次任务完工自动复盘，把做法蒸馏成 SOP，经审计才入技能树。同类活儿下一次干得更快更稳——它在你机器上越用越强，而不是越用越贵。

能力

0.4.0 真实能力清单

每一条都由当前 0.4.0 代码与本地验收覆盖——不是 roadmap。

penglai CLI 完全体

裸跑即聊，首次向导配模型；doctor、status、迁移，日常运维一个命令。doctor --export 可生成明确排除凭证与产品状态的脱敏诊断包。

文档与公开网页

导入并读取 PDF、Word、Excel、PPT，生成标准 PDF / DOCX / XLSX / PPTX；常用文档和代码产物可在桌面内只读文本预览；搜索和抓取真实公网页面并保留引用，联网每次由你确认。

审批四级制

L1 自主 / L2 一键 / L3 强制确认+溯源 / L4 拒绝，全程留痕可回放。

飞书渠道

聊天、开工、进度、审批卡片——完整工作流在 IM 里闭环。

Skill 与 MCP 生态

本地/GitHub Skill 可验哈希安装、启停和卸载；MCP 仅手动连接、不自启，每次工具调用都由你 L3 确认。完工 SOP 仍经蒸馏审计入树。

成本预算熔断

用量账本全程可见；预算触顶先熔断、再请示，不静默烧钱。

本地语音

SenseVoice ASR + MOSS-TTS-Nano ONNX CPU 全管线；桌面录音转写与逐条朗读都在本机完成。

主动陪伴

默认关闭；你选择安静、在场或主动。晨晚机会与情绪承接仍走同一 EpisodeRunner，不另起 Agent。

0.3 → 0.4 一键迁移

记忆、模型档案、身份，一条命令从 0.3 带过来。

桌面证据轨

安全 Markdown、普通文件 inbox、完整历史与完成通知；证据轨产物经项目围栏后可预览、直接打开或在 Finder 定位，事实来自真实观测，零 LLM 自述。

审批

点头，在聊天里完成

改变外部状态的操作——推送、发布、删改——按四级制必须你确认。审批卡直接推到飞书会话里：级别、操作、理由、任务一目了然，批准或拒绝一键完成。

谁发起、谁决定、何时发生，全程留痕可回放。也可以不用按钮：回复「批准 b3f1c9a2」同样生效。

架构

一个核心，三类薄门

Host 无头核心是唯一的产品核心；CLI、桌面、飞书与微信都是薄客户端——每条事实都来自 Host，客户端不持有产品状态。

0.3 的执行内核是 GenericAgent（致谢「基因」）；0.4 重写后，Pi 是引擎，Host 是产品。

安全与隐私

确定性护栏，不靠模型自觉

数据主权

  • 默认自托管API key、聊天记录、长期记忆、渠道凭据由本机持久保存；模型调用只发送当前任务需要的提示与上下文。
  • 审批留痕四级审批谁发起、谁决定、何时发生，全部落账，可回放。
  • 注入防线文档、网页与 MCP 返回都包裹为不可信数据；即使其中伪装成系统或 Owner 指令也不得执行，敏感动作仍走确定性审批。
  • 语音不出机SenseVoice ASR + MOSS-TTS-Nano 全在本机 CPU 完成，语音数据不出机。

BYOK · 自带 key

  • 11 家供应商目录内置安装向导逐项验活，key 存于本机 0600 私密文件。
  • OpenAI 兼容端点公网网关强制 HTTPS；HTTP 只允许本机 localhost / 127.0.0.1 / ::1。

快速开始

三行命令，把它叫醒

$ npm ci
$ npm run cli -w @penglai/host -- setup
$ npm run cli -w @penglai/host -- chat
# 首次配置后，进入同一个对话面
一
首次向导，一分钟接上大脑。选供应商 → 选计费 → 选模型 → 填 key → 真实调用验活，全程中文分页。
二
不想碰命令行？直接下载 Apple 芯片版或 Intel 版。桌面首次启动即同一只向导。安装包采用与 0.3.6 相同的本地签名方式，未购买 Apple 开发者证书、未公证；首次打开如被 Gatekeeper 拦截，请在“系统设置 → 隐私与安全性”中确认允许。
三
从 0.3 来？一条命令迁移记忆、模型档案与身份，老管家无缝换新引擎。
