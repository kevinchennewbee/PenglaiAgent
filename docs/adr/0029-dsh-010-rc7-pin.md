- 日期：2026-08-18
- 取代：ADR 0006 作为**当前产品 pin**（0006 仍是 R2 历史记录，不改写）

## Context

0.5.0 工作区此前精确钉 `@deepseek-ai/dsh@0.1.0-rc.6` / commit `47f943859bef60e4160492346772ded9b24f765a`。npm latest/next 已同为 `0.1.0-rc.7`，无 rc.8。Issue #3 U0 已重放 overlay SHA、零 diff 包运行时与 live official HTTP RPC。继续钉 rc.6 会落后官方 latest，并迫使前置向导在旧基线上完成后因升级再测一轮。

- U0 档案：`docs/compatibility/DSH_010_RC7_U0.md`

- overlay 三文件 SHA 与 Issue #3 §2.2 一致；keyed `settings.plugin.item` 合同变化归 U2

## Decision

选项：精确钉 `0.1.0-rc.7`，禁止 caret/latest。

- `PINNED_DSH=0.1.0-rc.7`
- `PINNED_DSH_COMMIT=99f6f02fecdb7dff40c3fbc9470f5907c29f74ca`
- `PINNED_DSH_INTEGRITY` 用上列 npm 值
- `overlays/dsh-0.1.0-rc.6/` 在 U2 按 ADR 0023 流程重建为 `overlays/dsh-0.1.0-rc.7/` 之前仍服务旧哈希；U1 不把旧 overlay 冒充 rc.7

## Security impact

无 fork；无第二 Agent/UI。漂移仍 fail closed。
