初心

如果 DSH 像 Linux，蓬莱想成为更容易抵达的发行层

不是再造一个 Agent，也不是给 DSH 换一张贴纸。蓬莱尊重「万物皆插件」：把安装、首次配置和常用能力组合好，让普通人也能真正用上 DSH。

0.5.0 是一次彻底重构：Agent、Workspace、Session、Turn、模型、工具和基础 Web UI 全部回到官方 DSH。0.5.1 则把这个选择做成三个平台都能安装的产品，并把核心同步到官方 DSH 0.1.1-rc.1。

这次还补上了真正能继续生长的插件中心。经过审核的 DSH 插件可以通过签名、不可变的 GitHub Release 加入目录，用户刷新、下载、确认权限并启用，不必为了多一款插件重装蓬莱。

开箱与组合

默认很干净，需要什么，再装什么

首次安装只有 DSH 核心与蓬莱插件中心。所有扩展默认关闭，安装、启用、停用与模型下载都由用户决定。

基础CORE

只用 DSH，也已经完整可用。

  • 官方 Web UI、工作区、会话、模型与工具
  • 首次向导选择 provider / model 并真实验证 API Key
  • 中文默认，支持 English 与浅色/深色/跟随系统
组合PLUGINS

像搭积木一样增加本地能力。

  • IM 可以单独工作，不依赖 ASR 或 TTS
  • ASR、TTS、Context、Memory、Budget、Companion 均可热插拔
  • 真实状态来自 DSH loader，不显示假卡片或静态“已安装”
蓬莱插件

1 + 1，大于 2

每个能力都遵循 DSH 插件边界；组合起来，才形成蓬莱独有的体验。

插件中心

从真实 DSH loader inventory 管理插件，并读取公开签名目录。只接受蓬莱审核、签名且哈希匹配的 Release，不开放任意 npm、Git 或 URL 安装。

消息连接 · IM

微信与飞书私聊接入，同一消息经过耐久 claim、官方 DSH Turn，再回到原渠道。扫码者默认是唯一允许身份。

本地语音识别 · ASR

SenseVoice 模型按需下载并显示进度。微信加密 SILK 在本机解码、识别，语言与情绪只作为内部辅助上下文。

MOSS-TTS-Nano

按需安装本地模型，把 DSH 的最终回复合成为语音。飞书使用原生音频消息；微信当前提供可靠可播放音频。

个人上下文

只索引你明确授权的目录，本机 SQLite FTS5 建立可删除的派生索引，不修改源文件。

分层记忆

区分全局、工作区和会话候选；长期记忆与 SOP 需要可见 diff 和你的确认，SOP 复用官方 DSH Skills。

Token 预算

消费官方 TokenMeter 与模型路由；价格不可信时只报 token，不编造金额，硬上限在新 Turn 前熔断。

主动陪伴

默认关闭。复用官方 Schedule、Session 与 Turn，受安静时段、每日上限、精确绑定和禁止无人值守工具约束。

架构

DSH 在中心，蓬莱在外围把体验做好

CORE

DeepSeek Harness

唯一 Agent 与 UI 核心

模型、工作区、会话、工具、审批、权限、基础 Web UI 与插件运行时均由官方 DSH 提供。

DISTRO

蓬莱桌面发行层

安装、引导、品牌与生命周期

内置目标架构 Node、Electron、固定 DSH closure 与许可证；不依赖 PATH、全局包或首次联网安装核心。

ECOSYSTEM

标准化插件生态

可选、可组合、可卸载

蓬莱第一方插件通过 DSH 官方 service、slot、Remote 与 loader 接入，不建立第二套 Agent 或聊天系统。

当前固定官方 DSH 0.1.1-rc.1。Penglai 0.5.1 不包含旧 Pi / Host 产品线，也不在旁边运行第二个 Agent。

隐私与安全

本地优先，但不对边界说漂亮话

你能明确知道什么留在本机

  • API Key 与渠道秘密走 DSH 官方 credentials seam，渲染器永远读不到明文。
  • macOS 凭据目录/文件使用 0700/0600 与原子写；同一系统用户的高权限进程仍可能读取，这是已公开边界。
  • ASR、TTS、索引、记忆、预算账本与陪伴计划可按类别查看和删除；工作区与授权源目录永不纳入应用删除计划。
  • 无云账户、无同步、无遥测。

联网、升级与信任说明

  • 调用你选择的云模型时，本次任务所需提示与上下文会发送到相应 provider。
  • 语音模型按需从固定来源下载并校验；核心首次启动不会联网安装依赖。
  • macOS 采用 ad-hoc 签名、没有 Developer ID、未公证；Windows 没有 Authenticode，系统可能显示安全提醒。
  • 0.5.0 → 0.5.1 需要手动覆盖安装并保留 0.5 代数据；从 0.5.1 起，后续同平台版本走签名、不可变 Release 和用户确认，不做静默更新。
