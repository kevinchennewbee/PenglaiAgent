English

蓬莱是官方 DeepSeek Harness 的桌面发行版。当前公开下载仍是 v0.5.6。0.5.7 是开发候选，安装包哈希在公网回读后填写。

消息连接

0.5.7 在唯一的消息连接插件下提供八个平台连接入口。

  • 微信 — 官方 iLink 扫码
  • 飞书 — 官方应用扫码 / 凭据
  • 钉钉 — 设备注册扫码 + Stream
  • 企业微信 — 智能机器人扫码
  • QQ — 官方机器人扫码，不是个人号
  • Slack — Bot Token + App Token，无官方扫码
  • Telegram — Bot Token 长轮询，无官方扫码
  • Discord — Bot Token + Gateway，无官方扫码
  • WhatsApp — 0.5.7 不捆绑社区协议 runtime

真实连接方式

用户只看到一个「消息连接」插件。微信、飞书、钉钉、企业微信与 QQ 使用各自真实的扫码或设备注册流程；Slack、Telegram、Discord 使用官方 Manifest 或 Token。WhatsApp 在本版本中没有连接动作。

0.5.7 同时补全

本轮还补全办公文档工作流、记忆候选与权限、主动陪伴、插件安装与回滚、Windows 生命周期和隐私门禁，不把 0.5.7 缩成一个 IM 换皮版本。

感谢 DSH-IM 社区提供多通道工程思路，并感谢 qqbot-agent-sdk 的 QQ 官方机器人接入参考。蓬莱在自己的 IM 控制平面内选择性重写这些思路，不捆绑两者的运行时。完整版本、许可证、取舍与来源见仓库的第三方清单和 provenance 记录。
