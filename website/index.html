蓬莱是官方 DeepSeek Harness 的桌面发行版。当前公开下载仍是 v0.5.6。0.5.7 是开发候选，安装包哈希在公网回读后填写。

消息连接

0.5.7 候选在唯一的消息连接插件下提供九个连接入口。公开“已支持”只以 live 证据矩阵为准，当前各平台为账号阻塞或未跑 live。

  • 微信 — 官方 iLink 扫码
  • 飞书 — 官方应用扫码 / 凭据
  • 钉钉 — 设备注册扫码 + Stream
  • 企业微信 — 智能机器人扫码
  • QQ — 官方机器人扫码，不是个人号
  • Slack — Bot Token + App Token，无官方扫码
  • Telegram — Bot Token 长轮询，无官方扫码
  • Discord — Bot Token + Gateway，无官方扫码
  • WhatsApp — 实验性社区协议，默认关闭

公开下载仍是 v0.5.6。macOS ad-hoc 未公证；Windows 无 Authenticode。
