它能做什么

每一条都在真实服务器上每天跑着，不是路线图

🎙️

听得出情绪的耳朵

本地 CPU 跑 SenseVoice（约 230MB）：语音转写 + 7 种情绪 + 声学事件。飞书/微信开箱即用，钉钉/QQ/企微由发行层封装补齐。

💬

多渠道，都是扫码

飞书扫码自动建应用、长连接免公网 IP；个人微信扫码登录；钉钉/QQ/企微/Telegram/Discord 一条命令接入。同一个管家，多个门。

🧠

四层记忆

索引/事实/技能/原始会话四层文件式记忆，纯 markdown 可审计；写入前威胁扫描（注入/角色劫持/密钥落库），禁止覆盖。

🛡️

确定性安全

危险命令与路径红线拦截 + 全量工具调用审计 + 出站文件白名单。安全靠确定性检查，不靠 LLM 自觉。

🌙

真主动，不扰民opt-in

心跳 + 硬编码门禁：勿扰时段、对话中绝不插话、频率上限。像朋友想起你，而不是闹钟响了。

🎛️

能力随时补开

第一次向导没开的，事后一条命令补上：penglai enable voice｜companion｜intel，penglai abilities 看全貌——不必重跑向导。

开始安装

没有 Python、没有 git 都不要紧，脚本全自动备好；国内网络自动走镜像

# 裸机一行，国内走 gh-proxy 镜像 curl -fsSL https://gh-proxy.com/https://raw.githubusercontent.com/kevinchennewbee/PenglaiAgent/main/install.sh | sh
# 自动取镜像→向导→常驻容器，数据在卷里升级不丢 curl -fsSL https://gh-proxy.com/https://raw.githubusercontent.com/kevinchennewbee/PenglaiAgent/main/docker-install.sh | sh
# PyPI 引导器，运行时拉取最新仓库 pip install penglai penglai setup
git clone https://github.com/kevinchennewbee/PenglaiAgent.git cd PenglaiAgent python3 penglai setup # 向导：语言→依赖→模型→渠道→能力面板

海上有仙山

为什么叫蓬莱

蓬莱是传说中的海上仙山，可望而不可即。

AI 之于普通人，正如蓬莱之于古人——明明听说了它的神通，却被一层迷雾挡在岸边：API、终端、配置，每一样都是劝退的礁石。

蓬莱想做那艘摆渡的船：会发微信，就该会用 AI 管家。八仙过海，各显神通——多模型、多渠道，每个人都能找到自己上岛的路。
