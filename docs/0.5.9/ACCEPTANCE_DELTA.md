# Penglai 0.5.9 acceptance delta / 蓬莱 0.5.9 验收增量

0.5.9 keeps the immutable 0.5.8 contract as history and renews every affected
gate for official DSH `0.1.2-alpha.2`. Historical alpha.1, source-only, UI-only,
cross-built, or copied evidence cannot satisfy this delta.

0.5.9 保留不可变的 0.5.8 历史合同，并针对官方 DSH
`0.1.2-alpha.2` 重新执行全部受影响门禁。alpha.1 历史证据、仅源码、仅 UI、
交叉构建或复制的证据均不能满足本增量。

## Required deltas / 必须增量

- Exact 257-package npm cohort with registry integrity and verified npm ECDSA
  signatures; no alpha.1/alpha.2 mixed closure.
- Real alpha.2 Gateway round-trip preserves namespaced Penglai `RemoteError`
  codes without exposing private diagnostics.
- Session projections reject unknown required events and fold current history
  instead of trusting a possibly stale list projection.
- DSH Home fresh and alpha.1 migration generations recover from interruption,
  bind current process/generation inventory, and prove required plugin health.
- Plugin Center refreshes post-action inventory and requires actual service
  health before commit or rollback.
- All nine adapters preserve inbound-to-official-Turn-to-outbound correlation;
  all supported live platforms renew Owner-account evidence.
- First-party settings pages observe the official alpha.2 connection generation,
  stop calls while disconnected, reload after reconnect, and discard stale
  generation results.
- Runtime closure rejects missing required peers, unexpected files, stale
  alpha.1 payloads, unsigned cohort metadata, and missing legal materials.
- Three native installers come from one clean `main` SHA. Each target passes
  installed E2E, plugin/Profile matrix, two-hour soak, real 0.5.8 upgrade, and
  default uninstall with Owner data preserved.
- Publication requires a redacted Owner live set: official provider nonce Turn,
  first user Turn, and all eight supported non-mock messaging platforms.
- The exact ten public assets, tag, target commit, hashes, signatures, SBOM,
  notices, and embedded identity are read back after immutable publication.

## Non-substitutable evidence / 不可替代证据

- A green source test does not prove installed or native behavior.
- A visible plugin card does not prove installation, activation, or health.
- A reconnect banner does not prove a dead Host was restarted.
- Opening update or uninstall settings does not prove an upgrade or uninstall.
- Draft upload success does not prove immutable public bytes.
