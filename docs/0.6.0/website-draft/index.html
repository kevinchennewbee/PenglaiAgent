Penglai 0.6.0

Official DeepSeek Harness 0.1.5-alpha.1 (dsh-v0.1.5-alpha.1, 5dda764e…, 272 packages). DSH is the only agent core. Office and Memory stay required.

Four installers from one clean main SHA: Apple Silicon, Intel Mac, Windows x64, UnionTech UOS 20 Professional 1070 (Loongson old-world Penglai_0.6.0_uos_loong64.deb).

Limits

  • macOS ad-hoc, not notarized. Windows has no Authenticode.
  • UOS native install/startup/function is Owner post-publication testing (OWNER_POST_RELEASE), never PASS before that.
  • UOS Electron 31.7.7 (Chromium 126, Loongson ftp zip 2025-02-06) is not maintained and is not a Chromium 150 / Electron 43 security equivalent. Shipping that limitation is a PM decision, not implied by source pins.
  • UOS userspace is old-world glibc 2.28 / /lib64/ld.so.1. Official npm koffi loong64 is new-world and is not shipped. JPEG in libvips is libjpeg-turbo, not mozjpeg. Mnemon 0.2.8 has no loong64 binary; Memory plugin is packed, the mnemon engine is unpublished. require-builtin native is unpublished; product web uses startup reload.
