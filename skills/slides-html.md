用户要做演示稿/PPT/幻灯片/slides，或说「科技风/极简风/乔布斯风」演示时，**不生成 pptx**——用 `file_write` 落一个**单文件、可直接双击打开、离线可用**的 `.html`。下面是方法论 + 关键步骤 + 易踩坑。

## 一、先想清楚（动笔前）
1. 没拿到讲稿就先 `ask_user` 要：主题、讲稿/要点、目标页数（没说就 8~20 页）、风格（没说默认乔布斯风）、横屏还是竖屏（默认竖屏 9:16，适合手机/朋友圈分享）。
2. **提炼讲稿**：一页只讲一件事。把原稿压成「每页一个核心观点 + 最多 3 条支撑」。不改原意，只做减法。
3. **起乔布斯风标题**：每页标题 ≤12 字，用对比式/问题式/断言式/数字式/比喻式之一，自检「这标题让人想继续看吗」。

## 二、设计规范（内联，照抄即可，不依赖任何外部规范文件）
- **比例**：竖屏 9:16（每页一个满屏 section，`height:100vh`）。要横屏就 16:9。
- **配色（深色科技风）**：背景 `#000` 或 `#0a0a0a`；主文字 `#fff`；辅助文字 `#9ca3af`；强调色一个就够（如 `#3b82f6` 蓝 / `#10b981` 绿），别堆多色。
- **字体**：直接用系统字体栈，**不引网络字体**（离线可开、无外站请求）：
  `font-family: -apple-system, "PingFang SC", "Microsoft YaHei", "Segoe UI", Roboto, sans-serif;`
- **字重/字号**：标题 `font-weight:800`、`clamp(2.2rem,7vw,4rem)`；正文 `font-weight:300~400`、`clamp(1rem,3.5vw,1.4rem)`。
- **留白**：禁止密集排版，section 内容垂直居中，左右留 8~10% padding。
- **背景光斑**（科技感来源）：纯 CSS 实现——2~3 个大号 `radial-gradient` 圆，`filter:blur(80px)`、低透明度，配一个 `@keyframes` 缓慢漂移。**不要**引任何动画库。

## 三、页型（按需挑，参考下面 5 种，别全用）
1. **封面页**：超大标题 + 一行副标题，居中。
2. **金句/断言页**：一句话占满屏，最大字号。
3. **列表页**：标题 + 2~3 条要点（带序号或小圆点），逐条留白。
4. **数字页**：一个巨大数字 + 一行说明（如「3 倍」「90%」），冲击力强。
5. **对比页**：左右/上下两栏对照。
> 易踩坑：别堆字、别上复杂图表、别花哨配色——偏离极简即失败。需要图就用 emoji 或纯 CSS 图形，不要外链图片。

## 四、交互（纯原生 JS，内联在 `<script>`，不引框架）
- 键盘 ← → 翻页（`scrollIntoView({behavior:'smooth'})` 切到上/下一个 section）。
- 触屏上下滑动 / 鼠标滚轮自然滚动即可（每个 section 满屏，CSS `scroll-snap-type:y mandatory` + section `scroll-snap-align:start` 自动吸附）。
- 底部一个细进度条/小圆点导航，标示当前页。
- **不需要 Vue/Tailwind 也能完成全部以上**——能内联最小 CSS 就别引 CDN。

## 五、落盘
- 用 `file_write` 写**一个** `.html`，结构：`<style>`（全部样式内联）+ N 个 `<section class="slide">` + `<script>`（翻页/进度，内联）。
- 写完把**绝对路径**告诉用户，提示「双击即可打开，离线可用，可发给别人」。
- 想 PDF/打印：让用户在浏览器里 Ctrl/Cmd+P 选「另存为 PDF」即可，**不调任何 PDF 生成库**。

## 六、关于 CDN（可选退路，非默认）
原技能用 TailwindCSS + Vue3 的国内 CDN。**蓬莱默认走上面「内联最小 CSS + 原生 JS」**，因为离线可开、无外站请求、无追踪、更稳。
仅当用户**明确要**很复杂的交互（如大量动态组件）且**接受需要联网**时，才可在 SOP 之外引官方 CDN（`cdn.tailwindcss.com` / `unpkg.com/vue@3`）——绝不用 `bytecdntp.com`/`fonts.loli.net`/`hdslb.com` 之类第三方代理 CDN。

## 安全
- 全程只 `file_write` 本地 HTML，不外发文件、不抓取外部内容来执行、不装任何依赖；生成的 HTML 默认零外站请求。红线/出站白名单照常生效。
