# Penglai 0.6.3 upstream decisions

Checked on 2026-09-18. These pins are immutable inputs for this release; later
upstream versions need a separate review.

| Dependency                   | Verified input                                                                                                                                                                                                                | Decision                                                                                                                                                                                                  |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DeepSeek Harness             | npm `0.1.6-alpha.2`; tag `dsh-v0.1.6-alpha.2`; commit `ddefc45fbc7f8e46dd73185e68295696d1297887`; tree `5aca5ee6f8dfd110dc3ae199fbddf8a0f606625f`; 307-package source cohort                                                  | Adopt the complete registry cohort with exact integrity. Do not mix rc.2, another alpha, source-path, Git, or locally repacked packages into the active graph.                                            |
| `fflate` security floor      | `0.8.3`                                                                                                                                                                                                                                                            | Apply a root resolution floor so the non-shipping upstream LibreOffice subtree cannot install vulnerable `0.8.2`; DSH package bytes and the 307-package DSH/vendor/native cohort remain exact.          |
| Session and client ownership | Session Controller inspection, explicit ownership lifecycle, subagent/sidebar and plan/deliverable changes                                                                                                                    | Replace deprecated synchronous Session reads with controller inspection. Keep DSH as the sole Session/UI owner.                                                                                           |
| DeepSeek image model         | `deepseek-flash` / `DeepSeek-V41-Flash`, with `text,image` input; the prior `deepseek-v4-flash-vision-exp` ID is absent; transport uses `/v1/messages` SSE                                                                    | Route image turns through the exact model and Messages wire protocol advertised by alpha.2; reject assumptions about the removed experimental ID or Chat Completions transport.                           |
| Runtime and tools            | new terminal, browser/computer-use, SSH, PTC, MCP resource, workspace-change, preview, and Office conversion packages                                                                                                         | Admit supported tools from the exact cohort. Penglai adds no parallel executor. Office conversion and document-preview packages are explicitly pruned from the product runtime.                          |
| Plugin management            | alpha.2 official manager exposes inspection, install/cancel/remove, enablement, and explicit build-script approval through `ProfileContext.packageManager`                                                                    | Use the exact official manager as the sole package-management engine. Penglai Center owns the one manager instance; official UI/tool stay enabled. Use application-owned Node/pnpm and no signed-catalog ecosystem allowlist. |
| Session log/privacy          | upstream session-log behavior is enabled by default                                                                                                                                                                           | Override it to disabled. No canonical conversation-log upload is accepted by default.                                                                                                                     |
| LibreOffice Kit              | six independent `@deepseek-ai/libreoffice-kit` `0.0.1` packages are present in the upstream graph                                                                                                                            | Audit their upstream identity, but prune all six packages plus DSH Office-to-PDF, Office skill, and document preview from the Penglai product runtime. No LibreOffice source or license obligation is claimed for unshipped bytes. |
| DSH IM references            | Penglai's reviewed first-party rewrite remains the product runtime                                                                                                                                                            | Keep `@penglai/im`. Do not install another IM host, WhatsApp, Office, or a second management API.                                                                                                        |
| Product scope                | Penglai historical source contains Office, Budget, and Companion workspaces                                                                                                                                                   | Exclude those workspaces from 0.6.3 and reject them in product-closure checks. Memory remains bundled/default-on but can be disabled without deleting code or data; management infrastructure stays required. |
| Node and Electron            | Node `22.23.2`, Electron `43.6.0` on Mac/Windows                                                                                                                                                                              | Keep current pins.                                                                                                                                                                                        |
| pnpm package runtime         | `11.11.0`; npm audit reports four high-severity issues in `11.7.0`, all patched by `11.11.0`                                                                                                                                | Pin `11.11.0` for repository CI and the application-owned plugin package runtime. Keep the DSH package cohort bytes unchanged.                                                                             |
| UOS runtime                  | Loongson Node `22.16.0`, Loongson Electron `31.7.7` / Chromium 126                                                                                                                                                            | Keep the old-world LoongArch runtime needed for UOS 20. Electron 31 is no longer maintained, so this is not security parity with Mac/Windows.                                                             |
| Mnemon                       | `0.2.8`, including architecture-built LoongArch engine                                                                                                                                                                        | Keep Memory bundled and enabled by default; preserve its package and data when the Owner disables Memory.                                                                                                 |
| `adm-zip`                    | npm `0.6.2`; integrity `sha512-Xwrja8nx9e5o2N1my4DsKCeKpdrnACyr1wtbPxBDgGzKzKyE9kRtBFA8mWldI+RVlD7CBZNWY/wQ2+ydwOR6kQ==`                                                                                                      | Override the ONNX toolchain's indirect dependency to the first release containing destination-symlink protection; keep install scripts disabled and verify the exploit shape directly.                    |

At the time of review, npm tags were `latest=0.1.5-rc.2`,
`next=0.1.5-rc.2`, and `alpha=0.1.6-alpha.2`. The release pins alpha.2 by exact
version and integrity rather than following a mutable tag.
