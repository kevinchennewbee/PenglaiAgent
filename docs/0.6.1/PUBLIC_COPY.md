# Penglai 0.6.1 staged public copy

Not a public download claim. Public README and websites stay on immutable
`v0.6.0` until GitHub Release `v0.6.1` bytes exist. Apply this copy after
those bytes exist.

## English

Penglai 0.6.1 installs official DeepSeek Harness `0.1.5-rc.1` (tag
`dsh-v0.1.5-rc.1`, commit `183f08e9c6dde7e36cd2318eaee70b0da08fb35e`, 279 npm
packages) on Apple Silicon, Windows x64, and UnionTech UOS 20 LoongArch.
Intel Mac is not a 0.6.1 publication target. DSH remains the only agent core. Office and Memory start on.
Mobile Messaging, speech recognition, voice generation, and Companion stay
optional and default off. WeChat and Feishu remain the native media channels.
An optional macOS iMessage private-text channel is default off, requires
manual Full Disk Access and Messages automation, and is unsupported on
Windows and UOS. Native iMessage live evidence is not claimed. WhatsApp
is not a Penglai channel.

Fresh install uses the official DeepSeek catalog, including
`deepseek-flash` (DeepSeek-V41-Flash) with text and image input. Existing
explicit model choices stay in official settings. Three installers must come
from one clean `main` SHA. Intel Mac, Linux amd64, and Windows ARM are not
0.6.1 targets.
Current native lifecycle is fresh install, restart, and default uninstall
on Mac/Windows. Old-version installed upgrade is not a 0.6.1 acceptance
gate.

UOS 20 old-world remains a packaged target. Native install,
startup, and function on a physical UOS host are `OWNER_POST_RELEASE`:
the Owner will test the published installer. Do not mark PASS from source
or cross-build evidence. The 0.6.0 UOS `OWNER_POST_RELEASE` record is
historical for that release only.
