Nothing hidden in the small print

Clear about what stays here, and what leaves.

Your work stays yours App data is stored locally by default. There is no Penglai account, cloud memory sync, or Penglai telemetry service. Model calls send task context to the provider you choose; connected messaging channels exchange content through their platforms.

Nothing leaves by surprise Plugin installation and build-script approval are separate trust actions. Once you connect a model or messaging channel, it processes tasks and messages under your settings; review permissions and recipients before enabling them.

A community release The code and release bytes are open to inspection. macOS and Windows may still show a security warning because this community build does not carry Apple notarization or Microsoft Authenticode.

One complete UOS installer The LoongArch .deb carries the app, Node, official DSH, the official package manager, Memory, IM, ASR, TTS, Budget, Companion, and Mnemon. It is designed for the same seven-step start; the Owner will verify that experience on a real UOS machine after publication.

Technical release boundaries

Official DSH includes a dormant DeepSeek OTLP endpoint; Penglai hard-disables it. Diagnostics must not contain credentials, chat bodies, QR codes, or private absolute paths. Penglai Ed25519 signatures bind updater and plugin bytes, but are not OS publisher identity. Mac and Windows embed Node 22.23.2 and Electron 43.6.0. UOS uses Loongson Node 22.16.0 and Electron 31.7.7 (Chromium 126), requires libatomic1, recommends bubblewrap, and cannot enable MOSS-TTS or iMessage. That Electron/Chromium runtime is unmaintained. UOS native install, startup, UI, file picker, sleep/resume, and function remain OWNER_POST_RELEASE. Default Defender-on Windows was not verified. This page does not claim a three-target native GUI PASS.

Release notes Security notes

Why Penglai

I spent more than ten years around networking, security, and operations, but I was not a software developer. Penglai began with one stubborn idea: ordinary people should be able to reach a real assistant from the computer they already have.

Computers travelled from command lines to windows and then into everyone's pocket. Agents should make the same trip. If I can send a message, I should be able to reach my own assistant. If it acts for me, I should be able to see what it was allowed to do, what actually happened, and what it cost.

Penglai has been rebuilt more than once. The important decision in 0.5 was to stop building another agent and stand on DeepSeek Harness instead. 0.6.6 keeps that decision, updates the exact official DSH cohort, and adapts the non-Office first-party plugins across three release targets, including UnionTech UOS 20 LoongArch. Older generations remain in Git history; their runtimes are not mixed into this core.

FAQ

The useful answers, before you install.

Is Penglai another agent?

No. Official DeepSeek Harness is the only core. Penglai owns install, lifecycle, and first-party plugins. There is no second chat page.

Which version should I download?

This page describes Penglai 0.6.6. Download the matching installer from the immutable v0.6.6 GitHub Release. Intel Mac is not a 0.6.6 installer. Published 0.5.10, 0.5.11, 0.5.12, 0.6.0, 0.6.1, 0.6.2, 0.6.3, and 0.6.5 remain historical and immutable.

Why does Gatekeeper warn?

macOS packages are ad-hoc signed and not notarized; Windows has no Authenticode. That is a stated limitation, not an OS endorsement. Do not turn off system security to install.

What starts on a fresh profile?

Memory and Mobile Messaging are installed and active, while messaging channels and accounts remain unconfigured. ASR and MOSS-TTS stay off. ASR, MOSS-TTS, Budget, and Companion are bundled but off by default. Office/PDF and LibreOffice are excluded.

Does Penglai support iMessage?

Only as optional macOS private text, default off. Grant Full Disk Access and Messages automation first, then enable and bind the exact peer. It is unsupported on Windows and UOS. Native live use is not claimed.

What if the API key fails?

The wizard supports Back, retry, and resume after restart. A failed credential test is never recorded as success.

Does uninstall delete my files?

Default uninstall removes the application and cache while preserving user data. Complete delete uses a separate category plan and must not recursively wipe a Workspace or home directory.
